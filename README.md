# ZH-L16C Analysis

Interactive web workbench for exploring the **Bühlmann ZH-L16C** decompression algorithm with **Erik Baker Gradient Factors** (`GF Low` / `GF High`) in metric units.

**Live Site:** [https://matthewlai.github.io/ZHL16C_Analysis/](https://matthewlai.github.io/ZHL16C_Analysis/)

> **Safety Disclaimer:** This project is strictly for mathematical, educational, and analytical exploration of decompression models and published dive tables. **Never** use profiles, schedules, or tables generated by this software to plan real dives.

---

## Implemented Capabilities

- **Single-Gas Nitrox ZH-L16C + GF Engine (`src/engine/`):**
  - Configurable $\text{O}_2\%$ (`21%` Air through `100%` $\text{O}_2$), `GF Low`, `GF High`, ascent/descent rates ($\text{m/min}$), deco step size ($\text{m}$), and last stop depth ($\text{m}$).
  - Exact closed-form **Haldane** (constant depth) and **Schreiner** (linear ascent/descent ramp) 16-compartment gas loading.
  - Supports both published Compartment 1 variants (`1b` = `4.0 min` $\text{N}_2$ and `1` = `5.0 min` $\text{N}_2$), selectable metric hydrostatic conversions, and continuous-ceiling vs. first-grid-stop `GF Low` ramp anchoring.
  - Computes **mandatory decompression stops only** (discretionary safety stops are never injected), No-Decompression Limits (NDL), Time to Surface (TTS), surfacing GF, $\text{ppO}_2$, and MOD (`1.4` / `1.6 bar`).
- **Interactive Profile & Ceiling Visualizer (`src/components/`):**
  - SVG depth-time chart with active GF ceiling shading, `GF Low` ceiling reference curve, highlighted mandatory stop staircase, interactive crosshair scrubbing, and live 16-compartment $\text{N}_2$ loading bars.
- **Cross-Validated Test Suite (`src/engine/__tests__/zhl16c.test.ts`):**
  - Unit and integration tests verified against analytical Haldane/Schreiner/ceiling test vectors and published reference profiles from **Subsurface**, **MultiDeco**, **Shearwater**, and **DecoTengu**.

## Local Development

Requires **Node.js 20+** and **npm**.

```bash
# Install dependencies
npm install

# Run unit & cross-validation tests
npm test

# Start local development server
npm run dev

# Lint and build static bundle
npm run lint
npm run build
```

## Deployment

Pushes to `main` automatically run `npm run lint`, `npm test`, and `npm run build` and deploy `./dist` to **GitHub Pages** via [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
